# رفع مشکل بیلد و ساخت خودکار فایل APK در گیت‌هاب (GitHub Actions CI)

## علت خطای بیلد در گیت‌هاب (۳ دقیقه و ۵۲ ثانیه):
۱. **فقدان لایسنس SDK 36 در سرورهای اوبونتو گیت‌هاب**:
   - پروژه از `compileSdk = 36` استفاده می‌کند؛ اما رانرهای رایگان GitHub Actions به صورت پیش‌فرض تا نسخه ۳۴/۳۵ را دارند و هنگام دانلود خودکار پکیج‌های اندروید ۱۶، به دلیل عدم پذیرش رسمی لایسنس‌ها متوقف می‌شدند.
۲. **کمبود حافظه (OOM Killer) به دلیل فلگ `-Dkotlin.compiler.execution.strategy=daemon`**:
   - در فایل قبلی ورک‌فلو، فلگ اجرای دیمن جداگانه کاتلین قرار داشت که باعث می‌شد دو ماشین مجازی جاوا همزمان (گریدل + دیمن کاتلین) بیش از ۷ گیگابایت رم رانر گیت‌هاب را مصرف کنند و سیستم‌عامل فرآیند را با سیگنال ۹ متوقف کند.
۳. **توقف کامپایل ریلیز با R8 و لینت (`lintVitalRelease` و `isMinifyEnabled = true`)**:
   - به دلیل ۲۳۸ درس آموزشی و ساختارهای داده بزرگ، بهینه‌سازی تهاجمی R8 و خطاسنجی سخت‌گیرانه لینت اندروید فرآیند ریلیز را با خطا مواجه می‌کرد.
